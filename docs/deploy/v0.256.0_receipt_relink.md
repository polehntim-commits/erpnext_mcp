**Deploy: v0.256.0 — a filed receipt pointed at an existing invoice or journal entry**

**Migrate needed**: one settings switch (Relink Expense Receipt, off). No phone change. **umbrel.local first.** Apply
after v0.255.0.

**1. Build (Tim)**

Push erpnext_mcp main (`__version__ = "0.256.0"`), build the fafo-erpnext image.

**2. Server, over SSH to umbrel.local**

```zsh
sudo docker exec -u frappe -w /home/frappe/frappe-bench fafo-erpnext_server_1 bench --site frontend migrate
sudo docker restart fafo-erpnext_server_1
sudo docker exec fafo-erpnext_server_1 grep __version__ /home/frappe/frappe-bench/apps/erpnext_mcp/erpnext_mcp/__init__.py
```

Expect `0.256.0`.

**3. Use it (when Tim chooses)**

1. ERPNext MCP Settings → tick **Relink Expense Receipt** (or open the Bookkeeping window).
2. `list_unmatched_receipts` → an Approved receipt whose bill was entered at the Desk → `relink_expense_receipt` with
   `linked_doctype: "Purchase Invoice"` and the invoice's name. Read the `warnings` (amount, supplier, draft, another
   receipt on the same bill).
3. A receipt on the wrong invoice: the same call with the right one and a `reason`. `unlink: true` with a reason clears
   it.

**4. Checks**

1. The receipt's Linked Document shows the invoice; its comments show "nothing → Purchase Invoice …" (or the old → new
   link and the reason).
2. A cancelled invoice, another company's, or an unapproved receipt is refused with nothing changed.

**5. Rollback**

The v0.255.0 image; links already set stay and are ordinary values.
