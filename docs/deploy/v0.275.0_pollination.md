**Deploy: v0.275.0 — pollination: the hive map**

**Migrate needed.** It adds:
- the config kind Pollination Plan;
- the Contractor Job kind Pollination, with an Operation field;
- the job template "pollination" and the "Distribute hives" / "Gather hives" templates;
- the Go / Hold preset `go_hold_spray_bees_out`, seeded **OFF**;
- a daily job;
- eight MCP switches (two reads ON, six writes OFF);
- three phone routes.

It pairs with **FarmOps 0.57.0** for the hive map on the phone. Contract: `docs/contracts/pollination_v0_275.yaml`.

**Pollination jobs are OFF for every company** until `pollination_enabled` is turned on for it. Nothing is created by
this release.

**1. Build (Tim)**

Push erpnext_mcp main (`__version__ = "0.275.0"`), build the fafo-erpnext image with `ERPNEXT_MCP_VERSION=0.275.0`.

**2. Server, over SSH to umbrel.local**

```zsh
sudo docker exec -u frappe -w /home/frappe/frappe-bench fafo-erpnext_server_1 bench --site frontend migrate
sudo docker restart fafo-erpnext_server_1
sudo docker exec fafo-erpnext_server_1 grep __version__ /home/frappe/frappe-bench/apps/erpnext_mcp/erpnext_mcp/__init__.py
```

Expect `0.275.0`.

**3. Before bloom (Tim or Santos; by February)**

1. `plan_hive_placement company=… season=2027 fields="Bing Block" loading_area="lat, lon"`. Optionally set
   `hives_per_acre`, `rate_per_hive`, and the machine (`{"pallets_per_trip": 6, …}`). Read the drops and trips back.
2. Desk → **Farm Config Version** → `pollination_plan:<company>_2027`. Check it, then **Publish**.
3. Turn on `pollination_enabled` for the company. Then run `create_pollination_job company=… season=2027
   supplier="<beekeeper>" start_date=… end_date=…`.
4. Move drops on the phone if needed (Work → Pollination → the map; Farm Manager), before the crew starts.
5. Turn on `job_links_enabled` for the company, mark the job ready and share the link with the beekeeper.
6. Bee safety: in the IPM map, add **harmed_by** edges from Honeybee / Mason Bee to the products that harm them.
   Then enable `go_hold_spray_bees_out` (Desk → Compliance Rule). It is Advisory.

**4. Checks**

1. The beekeeper taps Delivered with the count. The "Distribute hives — trip n" tasks appear on the board.
2. Record petal fall (BBCH 69) on a block. The next morning the gather-up trips appear, with one alert.
3. The beekeeper's Picked up is refused until the gather-up is done.
4. `get_pollination_status job=…` shows the five counts and any flags. Resolve each flag with a reason.
5. `link_pollination_invoice job=… invoice=…` compares the rental bill with the hives delivered.

**Rollback**

The v0.274.0 image. Plans and jobs stay and are ignored. The beekeeper's link stops when the route goes away.
