**Deploy: v0.265.0 — USDA AMS market prices, done right**

Apply after v0.264.1, on umbrel.local first. It needs a migrate. It has no phone part on its own: app 0.51.0 and the
v0.266.0 Desk dashboard build on top of it.

**The MARS API key (Tim, in the Desk; never in chat).** Go to ERPNext MCP Settings, find **USDA MARS API Key**, paste
it and save. The field is stored encrypted. The key is never logged or included in any answer.

**What the migrate adds**

- **Price records:** USDA Price Quote gains size, district, market type, a Not Quoted status, pack weight, volume,
  season and week, plus a row identity. Quotes already on the site are untouched.
- **Market Data Issue:** a new list of things to look at.
- **Market Commodity configs** for `sweet_cherries` and `cantaloupe`, published (version 1), holding:
  - report IDs, field names, sizes and packs;
  - grower deductions (cherries $0.60/lb, from the Constancy pool deal);
  - breakeven (cherries $1.22/lb, "Constancy 2027 draft pro forma"; replaced automatically when a Breakeven Analysis
    in $/lb is linked).
- **Setting `market_prices_enabled`:** OFF. When on, it runs a 05:30 pull of the last 7 days for every commodity in
  season.

**1. Server (umbrel.local)**

```zsh
sudo docker exec -u frappe -w /home/frappe/frappe-bench fafo-erpnext_server_1 bench --site frontend migrate
sudo docker restart fafo-erpnext_server_1
```

Expect `Market Commodity FCV-… seeded.` twice.

**2. Probe first (read-only against USDA)**

Switch on `allow_probe_market_report` and run `probe_market_report`:

- report 2412, from 2025-06-15 to 2025-07-15;
- report 2402, from 2026-07-01 to 2026-07-07;
- report 3284, from 2026-07-01 to 2026-07-03.

Each answer gives the field names, sample rows and any rows listed without a price, and is saved as a private File.
Send me the saved Files. They become the test fixtures and settle the field names, which were built from the
documented and third-party names.

**2b. Any other fruit or produce (configuration only, no code)**

1. Run `refresh_market_catalog` to load USDA's report index (no key needed). Desk → **Market Report** lists all
   1,690 reports.
2. Run `observe_market_reports` (the last 14 days of every current shipping-point report). Then
   `list_market_catalog` shows each commodity, the reports that carry it, and whether a config covers it.
3. Run `draft_market_commodity` for a commodity, e.g. `APPLES`. It builds a Draft from what the reports actually
   carry. Ten Drafts (apples … honeydew) are already seeded.
4. Add grower deductions and breakeven, then **publish in the Desk**. Only published commodities are pulled.
5. Request budget: the daily pull makes one request per distinct report, about 11 for cherries and cantaloupe and
   about 23 if all twelve are published.

**3. Backfill and switch on**

1. Switch on `allow_backfill_market_reports`.
2. Run `backfill_market_reports` with commodity `sweet_cherries` and seasons `[2023, 2024, 2025, 2026]`, then the
   same for cantaloupe if wanted.
3. Read `list_market_data_issues` (missing days, unknown sizes or packs, format changes).
4. Then tick **Market Prices: Daily Pull**.

**4. Checks**

- `get_grower_return_vs_breakeven` for sweet_cherries shows:
  - the latest 2412 quote by size;
  - grower return in $/lb against $1.22/lb;
  - terminal as context (the cost of market access);
  - volume.
- `get_price_trend` with size `10 row` returns candles. Days with no quote are gaps, and Not Quoted days are listed
  separately.
