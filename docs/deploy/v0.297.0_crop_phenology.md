**Deploy: v0.297.0 — crop phenology bases per crop (sweet cherry 40.1 °F)**

**Migrate.** The migrate seeds IPM setting `crop_phenology`:
- sweet cherry (also "cherry", "cherries", "sweet cherries", "Prunus avium"): 4.5 °C = 40.1 °F, cutoff 86 °F,
  citing ISHS Acta Horticulturae 1020_29; 41 °F (the WSU / uspest.org maps) is recorded as the alternate;
- every other crop: 50 °F.

Tools stay at 1,142; `config` takes kind `crop_phenology`. As with the pest models, it is published only by a
person in the Desk.

**What changed** (Tim, 2026-10-09)
- **Where the base comes from:** a crop's phenology base now comes from `crop_phenology`, which is config, not
  code. The Degree-Day Stage Table (ERPNext MCP Settings) still supplies the stages. Its `Crop: base =` line now
  applies only to a crop the setting has no row for.
- **No 50 °F for cherry:** the 50 °F base is never applied to cherry phenology. The validator refuses a cherry row
  at 45 °F or above.
- **Pest models are unchanged:** they keep their own published bases and units, in `pest_dd_models`.
- **In the output:** `get_degree_days` shows `base_f`, `base_source` and the alternates.

**1. Build (Tim)**

Push erpnext_mcp main (`__version__ = "0.297.0"`), then build with `ERPNEXT_MCP_VERSION=0.297.0`.

**2. Server**

```zsh
sudo docker exec -u frappe -w /home/frappe/frappe-bench fafo-erpnext_server_1 bench --site frontend migrate
sudo docker restart fafo-erpnext_server_1
```

Expect `IPM setting ipm_setting:crop_phenology@1 seeded.`

**3. Before relying on cherry degree days**
- **Stage table:** any cherry °F·day number (a Degree-Day Stage Table line, or a task template's GDD timing) must
  be on the 40.1 °F base. Neither server has a cherry stage table yet. The proposed sweet-cherry table should be
  drafted on this base.
- **Switching to 41 °F** to match the WSU / uspest maps: `config action=draft kind=crop_phenology`, set the
  cherry row's `base_f` to 41 (and clear `base_c`), preview, then publish in the Desk.
- **Calibrating:** `propose_harvest_calibration` against Tim's harvest windows suggests an offset, and a person
  publishes it.

**Rollback**

Roll back to the v0.296.0 image. Every crop goes back to 50 °F, or to its Degree-Day Stage Table line.
