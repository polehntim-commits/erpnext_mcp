**Deploy: v0.271.0 — contractor and supplier job links**

**Migrate needed.** It adds the doctypes Contractor Job and Contractor Job Link and the config kind Job Template. It
seeds three templates (orchard removal, supplier delivery, supplier pickup) and two prep checklists, and adds eight
MCP switches (two reads ON, six writes OFF). Pairs with **FarmOps 0.55.0**. Contract:
`docs/contracts/job_links_v0_271.yaml`.

**Sharing is OFF for every company** until it is turned on per company. No job is created by this release.

**1. Build (Tim)**

Push erpnext_mcp main (`__version__ = "0.271.0"`), build the fafo-erpnext image with `ERPNEXT_MCP_VERSION=0.271.0`.
Push fafo_ios and archive FarmOps 0.55.0, scheme FarmOps.

**2. Server, over SSH to umbrel.local**

```zsh
sudo docker exec -u frappe -w /home/frappe/frappe-bench fafo-erpnext_server_1 bench --site frontend migrate
sudo docker restart fafo-erpnext_server_1
sudo docker exec fafo-erpnext_server_1 grep __version__ /home/frappe/frappe-bench/apps/erpnext_mcp/erpnext_mcp/__init__.py
```

Expect `0.271.0`, and "job templates seeded: orchard_removal, supplier_delivery, supplier_pickup".

**3. The public path (no Funnel change)**

The job page lives at `<farmops_public_url>/farmops/api/job/<token>`. That is the same `/farmops/api` path the phones
already use through the Funnel, so **nothing in the Funnel config changes**. To check it:

1. ERPNext MCP Settings → **FarmOps Public URL** is set (e.g. `https://umbrel.tail2b0bb0.ts.net`).
2. `validate_public_endpoint` passes for `/farmops/api/health`.
3. After issuing a test link, open it on a phone off the farm Wi-Fi: the map and the job show.

Only if the health check fails from outside, check the Funnel on the host (read-only): `tailscale funnel status`. The
`/farmops` path must forward to the farmops service, as it already does for the phones.

**4. Checks**

1. Desk → **Contractor Job** → new from MCP:
   `create_contractor_job template=orchard_removal company=<a live company> fields="Block 1"`.
   Two prep tasks are raised; the status is Draft.
2. `create_job_link` is refused ("sharing job links is off"). Turn it on for that company only (Desk → Farm Feature
   Flag `job_links_enabled`, scoped to the company), mark the job ready, then issue a link.
3. Open the link: the map shows only that block, its valves and hazard pins, the entrance and Directions. A wrong or
   revoked link shows "Not found."
4. Phone (Farm Manager): Work → Contractor jobs → the job → **Share link** opens the share sheet with the link.
