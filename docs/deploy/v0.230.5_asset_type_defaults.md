columns on Farm Asset Type, one fetched flag on Asset Register, one patch, and the after-migrate tag URL rewrite).
No new tools, no settings, nothing on the phone (FarmOps stays 0.37.3). **Test on umbrel.local first;** OML is
Tim's call. `v0.230.4_tag_urls.md` has the tag detail.

**1. Build (Tim)**

**2. Server, over SSH to the box**

```zsh

sudo docker restart fafo-erpnext_server_1
```

Expect "slope limits are now data on Farm Asset Type — Tractor, Vehicle, Sprayer, Implement carry has_slope_limit

**5. Rollback**

The columns are additive. An older image ignores them and goes back to the four hard-coded types; an asset already
moved to Mini Excavator keeps its stored 10° but an older image would refuse to change it.
