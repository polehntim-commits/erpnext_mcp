# Deploy: crew tasks (server v0.213.0, app 0.25.0)

Contract: `docs/design/crew_tasks.md`. Rides on v0.211.0 and v0.212.0; deploying 0.213.0
delivers all three.

## 1. Server

1. Push `erpnext_mcp` `main`; build the image at the commit that carries
   `__version__ = "0.213.0"`. No new Python packages.
2. `bench --site <site> migrate`. Expect:
   - Farm Task: `work_mode`, `is_crew_task`, `crew_piece_unit`, `crew_sections`,
     `crew_headcount`, `crew_on_now`, `crew_person_minutes`, `crew_pieces`.
   - Farm Task Template: `work_mode`, `is_crew_task`, `crew_piece_unit`, `crew_sections`.
   - Farm Task Assignment: states `On Crew` / `Off Crew`; `pieces`, `piece_unit`, `section`,
     `part_done`, `member_notes`, `end_reason`, `added_by`, `ended_by`, `client_request_id`.
   - One Work tile seeded: `tile:crew_tasks@1` (needs app 0.25.0).
   - Patch `legacy_badge_prints_use_cr80` prints one or two lines: whether the "Employee Badge
     Card" print format was repointed to the CR80 card (an edited one is left alone and said so).
   - **No task is rewritten.** Every existing task is `Individual` and behaves as before.
3. ERPNext MCP Settings, to use it over MCP: `allow_add_to_crew_task`,
   `allow_remove_from_crew_task`, `allow_update_crew_task_member`,
   `allow_update_crew_task_sections` (all default OFF). `list_crew_task_members` is on.

## 2. App

Push `fafo_ios` `main`; build **0.25.0**.

## 3. Using it

Raise a crew task — in Desk set **Work Mode = Crew** on the task or its template, or over MCP:

```
create_farm_task  task_name: "Prune Block 4"  task_type: "Other"  work_mode: "Crew"
                  location_doctype: "Field"  location: "<block>"  piece_unit: "trees"
                  sections: [{from_row: 1, to_row: 20}, {from_row: 21, to_row: 40}]
                  evidence_required: {"photos": true, "findings_text": true}

add_to_crew_task  task: "<task>"  shift: "<the crew's Farm Shift>"  lead: "<foreman Employee>"
remove_from_crew_task  task: "<task>"  employees: ["<Employee>"]  reason: "Went home sick"
list_crew_task_members  task: "<task>"
```

On the phone (Foreman, Farm Manager, Crew Leader): Work → **Crew tasks**, or swipe a crew task →
**Add crew**. Pick people, scan badges, or "Everyone on my shift". The lead closes it with
Complete as on any task.

## 4. What to check after

- A crew task shows its crew; adding the same person twice says "already on".
- Somebody without the task's Required Certification is listed and cannot be added.
- A picker on a crew sees the task in My Tasks with "My part is done", and no Complete.
- Taking somebody off keeps their row (Farm Task Assignment, state Off Crew, with end time).
- After the lead completes it, nobody is still On Crew and the task shows people,
  person-minutes and pieces.
- An individual task assigns, claims and completes exactly as before.

## 5. Legacy badge and tag prints now draw the CR80 card

Print Badge Sheet and ID Card (Employee), Generate QR Sheet and QR Tag (Asset Register), the
"Employee Badge Card" print format on a badge row, and `generate_employee_id_card` all draw the
approved CR80 card: front and back, one per 85.6 × 54 mm page. Nothing in Desk needs changing —
the buttons are the same rows; the server answers the new card. Badges are still issued by
Print Badge Sheet / ID Card exactly as before.

- To check: Employee list → tick two people → Actions › Print Badge Sheet → four card-sized
  pages. Asset Register → an asset → Tags › QR Tag → the asset tag card.
- The old sticker-sheet and Letter layouts are behind the Farm Feature Flag
  `legacy_badge_layouts` (`set_feature_flag key: "legacy_badge_layouts" value: true`), default off.
- The company logo on the card is `Company.company_logo` / the badge logo; set it once and
  every one of these paths picks it up.

## 6. Decisions made here that Tim may want to reverse

1. **Crew pieces are not payable.** They roll up for cost per block; the payroll run does not
   read them. Piece-rate pay still comes from bucket scans.
2. **Crew Leader may add and remove crew** (with Foreman and Farm Manager).
3. **Unpaid breaks are not subtracted** from a person's minutes on a task.
4. **A person is on one crew task at a time** — adding them to a second moves them.
