**3. What changed**

1. Someone with a pay item, no salary structure and no hours in the period is paid the item on its own slip, with
   no base pay. State tax follows the item's **Work State**; if that is blank, it follows the state on the worker's
   last slip. Set Work State on an item for someone who has never been paid through this app. If someone worked
   without a structure, the item waits with their hours, and the run lists it under `pay_items_waiting` with the fix.
2. A daily-pay worker with no daily slip in the week still gets a weekly settlement for an item dated in that week.
3. Cancelling a payroll run puts the items it paid back to Pending. The next run for the period pays them and shows
   `released_from`. This also holds when the status was written without a save.

**Rollback**

Roll back to the v0.292.0 image. Items then behave as before: a cancelled run's items need setting back by hand.
