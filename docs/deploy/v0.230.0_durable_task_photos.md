# Deploy: v0.230.0 — Farm Task photos, per photo (app 0.37.0)

Code only; no migrate, no settings.

**Test on umbrel.local only.**

1. Build at `__version__ = "0.230.0"`; restart workers. Ship app 0.37.0.
2. Claim and start a task that needs photos. Airplane mode. Take before and after photos, complete it.
   The task shows **Completed — photos pending (0 of N uploaded)**; each photo shows **Saved on phone**.
3. Force-quit, reopen: still there. Back online: photos go **Uploading** → **Uploaded** one by one (the
   queue now sends the moment signal returns, as well as on launch, foreground and every minute), then the
   task shows **Completed** and the Desk has the assignment with every photo.
4. Turn airplane mode on half way through a large photo, then off: it resumes; the task is completed once,
   with each photo once (a resent completion is answered `replayed`).

Server: `complete_task_via_mobile` takes `client_request_id`; a resend gets the first answer back.
