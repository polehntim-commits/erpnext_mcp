**Deploy: v0.282.0 — one share-link tool (consolidation phase 4)**

**No migrate.** One new MCP switch, `allow_share_link`, off by default. Tools go from 1,140 to 1,141: one is added,
and nothing is removed or hidden.

**1. Build (Tim)**

Push erpnext_mcp main (`__version__ = "0.282.0"`), build the fafo-erpnext image with `ERPNEXT_MCP_VERSION=0.282.0`.

**2. Server**

```zsh
sudo docker restart fafo-erpnext_server_1
sudo docker exec fafo-erpnext_server_1 grep __version__ /home/frappe/frappe-bench/apps/erpnext_mcp/erpnext_mcp/__init__.py
```

Expect `0.282.0`.

**3. Turning it on (Tim)**

ERPNext MCP Settings: tick **Share link (every kind)** (`allow_share_link`). Reads (get, list, log) work at once. A
create, extend or revoke also needs that kind's own switch (`allow_create_job_link`, `allow_issue_packer_credential`,
`allow_request_upload_url`, `allow_issue_enrollment_link`, …), and the kind's company flag (job links, packer portal)
as before. Reconnect the MCP client, then start with `share_link action=kinds`.
