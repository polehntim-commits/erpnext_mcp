   `{"path": "weather.forecast.daily[0..6].rain_risk_cum_pct", "agg": "max", "op": "lt", "value": 40}`. Each day
   shows Go or "Hold: … " with the actual value. Nothing is written.

4. Error Log: no "Weather" errors after a preview.
