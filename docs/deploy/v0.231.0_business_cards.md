**Deploy: v0.231.0 — business card → Contact (app 0.38.0, AFB-2026-00031)**

**Migrate needed**: six Contact custom fields and two ERPNext MCP Settings switches. Two new MCP tools: `search_contacts` (read, on) and `save_contact` (write, off).
**umbrel.local only.** Apply after v0.230.6 (or build straight to this one; every earlier migrate is idempotent and
runs in the same `bench migrate`).

**1. Build (Tim)**

Push erpnext_mcp main (`__version__ = "0.231.0"`), build the fafo-erpnext image. Archive and ship FarmOps 0.38.0
(build 25) from fafo_ios main.

**2. Server, over SSH to umbrel.local**

```zsh
sudo docker exec -u frappe -w /home/frappe/frappe-bench fafo-erpnext_server_1 bench --site frontend migrate 2>&1 | grep -i "business-card"
sudo docker restart fafo-erpnext_server_1
sudo docker exec fafo-erpnext_server_1 grep __version__ /home/frappe/frappe-bench/apps/erpnext_mcp/erpnext_mcp/__init__.py
```

The migrate grep prints nothing when the Contact fields went in (it prints a line only if they did not). Expect
`__version__ = "0.231.0"`.

**3. Checks**

1. Desk → Contact → any contact: the form has Captured From, Met On, Met At, Website and Captured By.
2. Desk → ERPNext MCP Settings: "Search Contacts" is ticked (a read, on by default like every read tool) and
   "Save Contact" is unticked (a write). Untick Search Contacts if Claude should not read contacts; the phone needs
   neither. (Corrected 2026-10-04: this line first said both were unticked.)
3. `search_contacts` with a name you know returns that contact.

**4. Phone (0.38.0)**

1. Signed in as a Farm Manager (or Accounts / System Manager): Receipts shows "Scan business card" top left. A Field
   Worker does not see it.
2. Photograph a card: the form opens with the name, title, company, phones, emails and website filled in. Fix
   anything wrong, add where you met, tap Save. The Work tab badge counts it until it lands; then Desk → Contact
   has it, with the photo attached and Captured From = Business card.
3. Scan the same card again: "Already on file" offers "Update …" (selected) or "Save as a new contact". Update adds
   only what was missing.
4. A card from a company that is already a Supplier offers "Supplier: <name>" under Link to; saving links the
   contact to that supplier.
5. Photograph a business card with the receipt camera instead: "This looks like a business card" appears on the
   "What is this?" screen with "Save as a contact instead".
6. Airplane mode: scan and save a card; it waits in the queue and files once the signal is back, once.

**5. Rollback**

The Contact columns and the two switches stay and are harmless. Contacts filed stay. An older app never calls the
new routes.
