**Deploy: v0.333.0 — Trailing 12 Months on the financial statements**

**Migrate**: new Script Report `Financial Statements TTM` (module ERPNext MCP). Tools: **1,156** (unchanged).
No phone change.

**Why** (Tim): "On the financial statements is there a way to do a trailing 12 month view. Right now we have Fiscal
Year, and date range. TTM would be awesome to add to the view."

**What changed**
- Desk → search "Financial Statements TTM": pick Profit and Loss, Balance Sheet or Cash Flow; As of defaults to the
  last month-end; Monthly Columns and Compare Prior TTM are checkboxes. The numbers are ERPNext's own statements
  over a date range; ERPNext's Fiscal Year / Date Range reports are unchanged beside it.
- MCP: `run_report name="Profit and Loss Statement" period=TTM` (also Balance Sheet, Cash Flow).

**After deploy (Tim; nothing was written to OML by this release)**

1. Open it and pin it (Desk → Financial workspace → Edit → add a Link → type Report → Financial Statements TTM):

```sh
open "https://<desk host>/app/query-report/Financial Statements TTM"
```

2. Check over MCP:

```sh
run_report name="Profit and Loss Statement" period=TTM compare_prior=true filters={"company": "<company>"}
run_report name="Balance Sheet" period=TTM compare_prior=true filters={"company": "<company>"}
```

   The comparison needs a Fiscal Year covering the prior twelve months; without one the result says so and shows
   the current TTM alone.
