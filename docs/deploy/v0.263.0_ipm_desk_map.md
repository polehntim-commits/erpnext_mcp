**Deploy: v0.263.0 — the IPM Map in the Desk**

**Migrate needed:** the page `ipm-map` and the workspace links. There is no phone change. Apply it after v0.262.0, on
**umbrel.local first**.

**What it does (Tim, 2026-10-06)**

- **One graph, three surfaces.** /app/ipm-map draws the same IPM graph that the phone and MCP read, through the same
  function, and changes it only behind the same rule. Only a Farm Manager, Compliance Officer or System Manager can
  add, edit or disable a relationship; everyone else can view.
- **Filters:** crop or variety; BBCH stage, or a date (which uses the block's stage as seen by then); block; kind;
  relation; provenance; depth.
- **Reading the drawing:**
  - Colour and shape show the kind; line style shows the relation.
  - A blue double ring marks an MBTA-protected species.
  - A red ring marks a product that would harm a beneficial active now.
  - A faded node is not active at this stage.
- **Click a node** to see its details, its relationships, its thresholds and the last 20 observations.
- **Editing (Manager / Compliance):**
  - Add a relationship with "Add relationship", or switch Connect on and drag from one node to another.
  - Click an edge to edit it, disable it or enable it.
  - A literature edge is never changed: the farm's own copy is saved beside it and shown instead.
- **Export:** PNG, SVG or CSV of the current view.
- **No internet needed for the graph:** the library is served from the app (`/assets/erpnext_mcp/vendor/cytoscape`).
  (The other Desk maps still load Leaflet from a CDN; this one doesn't depend on it.)
