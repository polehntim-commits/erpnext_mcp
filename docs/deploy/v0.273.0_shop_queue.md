**Deploy: v0.273.0 — the shop queue**

**Migrate needed.** It adds four Shop Work fields to Farm Task Template and thirteen shop templates. Three are
enabled (service due, count and reorder, print tags). The ten Mid-Columbia starters are disabled. It also adds the
Today tile "Shop work today", an hourly job and three MCP switches (two reads ON, one write OFF). **No phone update.**
Contract: `docs/contracts/shop_queue_v0_273.yaml`.

**1. Build (Tim)**

Push erpnext_mcp main (`__version__ = "0.273.0"`), build the fafo-erpnext image with `ERPNEXT_MCP_VERSION=0.273.0`.

**2. Server, over SSH to umbrel.local**

```zsh
sudo docker exec -u frappe -w /home/frappe/frappe-bench fafo-erpnext_server_1 bench --site frontend migrate
sudo docker restart fafo-erpnext_server_1
sudo docker exec fafo-erpnext_server_1 grep __version__ /home/frappe/frappe-bench/apps/erpnext_mcp/erpnext_mcp/__init__.py
```

Expect `0.273.0`.

**3. Make it yours (Tim or Santos, in the Desk; optional)**

1. Desk → **Farm Task Template**: enable the starters you use, and edit their tools and safety notes. Tick **Shop
   Work** on any of your own indoor templates.
2. Learners: add `shop_learner` to that person's skills on their Employee record (Antony). Skilled jobs then name
   them in the pairing note.
3. Optional, per company, in Desk → **Farm Feature Flag**:
   - `shop_day_hours` (Threshold, default 8);
   - the weather thresholds (`shop_day_rain_pct` 60, `shop_day_rain_in` 0.10, `shop_day_wind_mph` 20,
     `shop_day_gust_mph` 30, `shop_day_cold_f` 32);
   - `shop_day_declared` (Text, e.g. "2026-11-03 smoke") for a smoke day;
   - `shop_evening_notice` (Flag) and `shop_evening_hour` (Threshold, 17) for the evening heads-up.

**4. Checks**

1. `list_shop_backlog company=…`: open winterize tasks first, then machine repairs. Suggestions list machines whose
   service is due, low stock and tags to print.
2. `get_weather_day_plan company=…`: today's verdict with reasons, and the list that fits 8 hours.
3. Phone (Foreman / Farm Manager): on a rainy day the Today tile **Shop work today** lists the jobs. On a dry day it
   shows nothing.

**Rollback**

The v0.272.0 image. The template fields stay and are ignored, and shop tasks stay as ordinary Farm Tasks.
