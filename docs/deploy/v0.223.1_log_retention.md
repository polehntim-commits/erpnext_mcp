# Deploy: v0.223.1 — get_security_status log retention

Code only; no migrate needed. Rides on v0.223.0.

1. Build at `__version__ = "0.223.1"`; restart workers.
2. On OML `get_security_status` → `log_retention` is `pass` with "Kept: Error Log 30 days, Activity Log
   365 days, Access Log forever (no row)."
3. Nothing to change in Log Settings. Access Log has no row in Logs to Clear by default, which means it
   is never cleared. To set a limit: Desk → Log Settings → Logs to Clear → Add Row → Log DocType =
   Access Log, Clear Logs After (days) = 90 or more.
