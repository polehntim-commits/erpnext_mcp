# Deploy: v0.219.0 — approve a new phone from a phone (OFF by default)

Rides on v0.218.0. Code plus one migrate (a new doctype, Farm Access Request; one setting). App 0.29.0.

1. Build at `__version__ = "0.219.0"`; migrate; restart workers and the sidecar. Nothing changes.
2. To use it (Tim's decision; needs Device keys enabled first): tick **Approve new phones from a
   phone**. The new phone: Sign in → "New phone" → scan the Join code from a signed-in phone (or type
   the farm address) → it shows a code. The manager: Settings → Approve a phone → scan or type the
   code → choose the person → Face ID. The new phone signs in by itself.
3. Desk fallback (System Manager): `erpnext_mcp.api.access.decide` with the code, the person and
   `approve` or `deny`.

Every approval sends a security alert. The person must already have a mobile account.
