**Deploy: v0.331.0 — Apple Pay device numbers matched as their card**

**Migrate**: new doctype Bank Card Alias; Expense Receipt gains `card_alias` (read-only Link). Tools: **1,153 → 1,156**
(`list_bank_card_aliases` read, on; `add_bank_card_alias` / `remove_bank_card_alias` mutating, off).

**Why** (Tim, "4 sounds good"): receipts from Apple Pay purchases print the phone's device account number (••7637,
••6991), not the card's last four. The bank line says CARD 0845, so the matcher never saw a card match and these
receipts matched on amount / date / merchant alone.

**What changed**
- A register of cards per Bank Account: the card's own last four plus each phone's number.
- The receipt matcher treats a registered device number as its card (boost when the bank line names the card), and
  a receipt whose card belongs only to a different bank account gets a mild penalty (0.05, never a block).
- New receipts get `card_alias` set at capture; adding an alias tags the receipts already scanned with that number.

**After deploy (Tim applies over MCP; nothing was written to OML by this release)**

1. ERPNext MCP Settings: tick Add Bank Card Alias (and Remove Bank Card Alias if wanted). Reconnect the MCP client.
2. Find the Wells Fargo 3158 business account's docname:

```sh
query_doctype doctype="Bank Account" fields=["name","account_name","bank_account_no","company"]
```

3. Seed the card and both Apple Pay numbers (replace <WF 3158> with that docname):

```sh
add_bank_card_alias bank_account="<WF 3158>" card_last_four="0845" label="WF business card 0845"
add_bank_card_alias bank_account="<WF 3158>" card_last_four="0845" number="7637" kind="Apple Pay" label="Apple Pay – device 7637"
add_bank_card_alias bank_account="<WF 3158>" card_last_four="0845" number="6991" kind="Apple Pay" label="Apple Pay – device 6991"
```

4. Check:

```sh
list_bank_card_aliases bank_account="<WF 3158>"
auto_match_receipts company="<company>"
```

   Each add reports `receipts_tagged`; in `auto_match_receipts`, proposals for 7637 / 6991 receipts show
   `card_fingerprint: true` and `signals.card_alias_hit: true` where the bank line names CARD 0845.
