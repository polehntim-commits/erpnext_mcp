**Deploy: v0.335.0 — The public website**

**Migrate**: new doctype Public Site Entry; Farm Config Version gains the kind Public Site; Job Applicant gains three
Custom Fields (Public Site Answers, Preferred Language, Public Site Source). Tools: **1,159 → 1,175**. Settings:
**Public Site Enabled** (off) and sixteen tool switches (reads on, writes off). No phone change.

**What it is**
- A public site under one prefix (default `/farm`): pages, jobs, crew information, report a problem, visitor check-in
  and check-out, QR codes. English / Spanish.
- Nothing is served until a person ticks **Public Site Enabled** AND a site config is published. Before that every
  path under the prefix is the site's ordinary 404.
- Only the company named in the site config appears; no other company's name, openings or data is ever rendered.

**Paths that must be reachable from the internet** (and nothing else for this feature)

```sh
/<prefix>
/<prefix>/*
```

`get_public_site` returns them for the configured prefix (`funnel_paths`). The Desk, `/app`, `/api` and login are not
needed by the public site.

**After deploy**

1. ERPNext MCP Settings → Public Website: tick the write tools you want an AI to use. Leave **Publish Public Site**
   off to publish in the Desk yourself (Farm Config Version → Publish). Reconnect the MCP client.
2. Build it over MCP:

```sh
configure_public_site company="<public company>" brand_name="<name>" base_url="https://<public host>" qr_sources=[{"tag":"gate","label":"Front gate"}]
set_public_site_page slug=home blocks=[{"type":"heading","text":{"en":"…","es":"…"}},{"type":"text","text":{"en":"…","es":"…"}}]
set_public_site_form form=report routing={"notify_roles":["Farm Manager"]}
preview_public_site path=""
publish_public_site change_note="first public site"
```

3. Tick **Public Site Enabled**. Open `https://<host>/<prefix>` in a private window.
   A 404 there with the site enabled and published means a stale hooks cache: `bench --site frontend clear-cache`.
4. Expose only the two paths above.
5. QR codes: `generate_public_site_qr path=visit src=gate format=sign_pdf`.

**Turning it off**: untick Public Site Enabled. Published content is kept; nothing is served.
