**Deploy: v0.281.0 — one record tool, one document tool (consolidation phase 3)**

**No migrate.** Two new MCP switches, `allow_record` and `allow_document`, off by default. Tools go from 1,138 to
1,140: two are added, and nothing is removed or hidden.

**1. Build (Tim)**

Push erpnext_mcp main (`__version__ = "0.281.0"`), build the fafo-erpnext image with `ERPNEXT_MCP_VERSION=0.281.0`.

**2. Server**

```zsh
sudo docker restart fafo-erpnext_server_1
sudo docker exec fafo-erpnext_server_1 grep __version__ /home/frappe/frappe-bench/apps/erpnext_mcp/erpnext_mcp/__init__.py
```

Expect `0.281.0`.

**3. Turning it on (Tim)**

ERPNext MCP Settings: tick **Record (every register)** (`allow_record`) and **Document (submit, cancel, approve …)**
(`allow_document`). Reads work at once. A create, update, delete or state change also needs that type's own switch
(`allow_create_supplier`, `allow_submit_purchase_order`, …), as before. Reconnect the MCP client, then start with
`record action=types` / `document action=types`.
