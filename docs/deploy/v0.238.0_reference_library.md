**1. Build (Tim)**

Push erpnext_mcp main (`__version__ = "0.238.0"`), build the fafo-erpnext image.

**2. Server, over SSH to umbrel.local**

```zsh
sudo docker exec -u frappe -w /home/frappe/frappe-bench fafo-erpnext_server_1 bench --site frontend migrate
sudo docker restart fafo-erpnext_server_1
sudo docker exec fafo-erpnext_server_1 grep __version__ /home/frappe/frappe-bench/apps/erpnext_mcp/erpnext_mcp/__init__.py
```

Expect `__version__ = "0.238.0"`.

**3. First load (the OSU/WSU cherry pruning and firmness papers)**

1. Desk → ERPNext MCP Settings: check the vocabularies (Reference Library — Crops / Topics / Regions) and edit them;
   tick **Add Reference** and **Update Reference**.
2. Put the PDFs in `~/Documents/Farm-Training/Cherry-Pruning/` on the Mac (the folder is not there yet). For each:
   `add_reference` with `file_content` (base64, up to 8 MB — larger ones once upload links land), `title`,
   `ref_type: "Extension Guide"` or `"Research Paper"`, `publisher`, `year`, `source_url`, `crops: ["Sweet
   Cherry"]`, `topics: [...]`.
3. A scanned PDF comes back `text_status: "OCR pending"` with `pages_pending_ocr`. On the Mac:
   `swift tools/mac/library_ocr.swift paper.pdf 3 4 5` prints `{"3": "…", …}`; pass that as `page_texts` to
   `update_reference`. The status becomes "OCR'd" when no page is missing.

**4. Checks**

1. `search_references` `query: "bacterial canker pruning"`: hits with the document, the page and a short snippet.
2. `get_reference` with `pages: "2 3"`: the text of those pages; `cited_by` empty until something cites it.
3. Desk → Compliance Policy (or a Farm Task Template, Training Type, Compliance Rule, Inspection Template): a
   References table; add a row citing the paper and its page — `get_reference` then lists it under `cited_by`.
4. The PDF is private: its File is not reachable without a login.

**5. Rollback**

Everything is additive. An older image ignores the doctypes; the PDFs stay as private Files.
