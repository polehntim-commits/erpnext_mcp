# Deploy: v0.222.0 — office@ reply drafts (OFF by default; sent only by a person)

Rides on v0.221.0. Code plus one migrate (settings, seven switches, the Office Mail form's buttons).
Contract: `docs/design/office_reply_drafts.md` §2–§5.

**Deploying changes nothing.** Every draft and send tool is off; nothing drafts by itself (there is
no model on the server); nothing is ever sent except by a person's approval.

1. Build at `__version__ = "0.222.0"`; `bench migrate`; restart workers.

## Before turning it on (Tim's decisions)

- Approvers per class: the defaults (Accounts Manager/User for customer, supplier, invoice;
  HR Manager for training/personal; Compliance Officer/Farm Manager for compliance; System Manager
  always) or JSON in **Reply approvers by class**. Note: approving in the Desk as the same user that
  is the **MCP System User** is refused — approve as yourself.
- Style notes per company: a Farm Feature Flag `mail_style_notes` (kind Text, scoped to the company),
  e.g. "Sign as Orchard Meadow office. Short. No exclamation marks. Spanish if they wrote in Spanish."
- **Test the send on umbrel.local first** with a test mailbox: the standalone suite cannot run
  Frappe's real `communication.email.make`. Confirm the reply arrives from office@ (not the
  approver's address — `always_use_account_email_id_as_sender` is on for Zoho since v0.216.1), in the
  same thread, with the company footer.

## Using it

2. Triage must be on (v0.221.0). Turn on `allow_list_mail_needing_drafts` and
   `allow_get_mail_context` (reads, on by default) and **`allow_save_mail_draft`** only.
3. Drafting: in Claude Code with the OML MCP, ask it to "draft replies for office mail needing
   drafts". It pulls the queue, reads each context, and saves drafts. It cannot send: leave
   `allow_approve_mail_draft` off — approval is the Desk.
4. Review in the Desk: /app/office-mail → filter State = Drafted → open → **Approve and send** (edit
   the text, tick any attachment, confirm financial details when asked) or **Discard**.
5. Flagged mail (red banner, state Needs person) gets no draft. A bank-detail change: phone the
   supplier on the number already on file, never one in the email.

Rollback: switch `allow_save_mail_draft` off. Sent mail is a normal Communication; nothing to undo.
