**Deploy: v0.280.0 — one config tool (consolidation phase 2)**

**No migrate.** One new MCP switch, `allow_config`, off by default. Tools go from 1,137 to 1,138: one is added, and
nothing is removed or hidden.

**1. Build (Tim)**

Push erpnext_mcp main (`__version__ = "0.280.0"`), build the fafo-erpnext image with `ERPNEXT_MCP_VERSION=0.280.0`.

**2. Server**

```zsh
sudo docker restart fafo-erpnext_server_1
sudo docker exec fafo-erpnext_server_1 grep __version__ /home/frappe/frappe-bench/apps/erpnext_mcp/erpnext_mcp/__init__.py
```

Expect `0.280.0`.

**3. Turning it on (Tim)**

ERPNext MCP Settings: tick **Config (every kind)** (`allow_config`). Reads work at once. A draft, stage, publish or
rollback through `config` also needs that action's own switch (`allow_draft_config`, …), as before. Reconnect the MCP
client, then start with `config action=kinds`.
