# OML cutover C1–C11 — paste-ready (zsh)

Every phone check: **cellular, Tailscale OFF**. Every `curl` is run from a laptop on a phone
hotspot with Tailscale OFF. The blocks contain no comments and no `$TS` variable: zsh does not split
`$TS` into words, so `$TS serve status` would fail; each command is written out in full.

Targets on OML:
- sidecar: `http://127.0.0.1:5250` (farmops-fwd); the mount target carries the path → `http://127.0.0.1:5250/farmops`
- ERPNext: **`http://127.0.0.1:5300`**, no path. This is what the current `/erpnext` handler must
  point at, because `…/erpnext/farmops/api/health` reaches the sidecar today. **Confirm it in the C1
  output** — the `"Proxy"` value under `"/erpnext"` — and if it differs, use that value in C8 and in
  the rollback instead.

## C1. Snapshot (this file is the rollback)

```zsh
sudo docker exec tailscale_web_1 tailscale serve status --json | tee ~/funnel-before-$(date +%F).json
sudo docker exec tailscale_web_1 tailscale funnel status
```

Read it: the `"Proxy"` under `"/erpnext"`; whether anything is under `"/"`; whether `/farmops`
already exists.

## C2. Publish /farmops (add before removing anything)

```zsh
sudo docker exec tailscale_web_1 tailscale funnel --bg --https=443 --set-path=/farmops http://127.0.0.1:5250/farmops
sudo docker exec tailscale_web_1 tailscale funnel status
```

Verify from outside the tailnet:

```zsh
HOST=https://orchardmeadow-umbrel.tail2b0bb0.ts.net
curl -s $HOST/farmops/api/health
curl -si -X POST -H 'Content-Type: application/json' -d '{}' $HOST/farmops/api/mobile/scan_asset | head -1
curl -si -X POST -H 'Content-Type: application/json' -d '{}' $HOST/farmops/api/mobile/not_a_route | head -1
curl -s $HOST/farmops/api/scan/TEST
```

Expect, in order: `{"ok": true, "service": "farmops-api"}`; `HTTP/2 401`; `HTTP/2 401`; plain text
starting `Farm Ops tag: TEST`.

## C8. Remove the public /erpnext mount; keep ERPNext on the tailnet

```zsh
sudo docker exec tailscale_web_1 tailscale funnel --https=443 --set-path=/erpnext off
sudo docker exec tailscale_web_1 tailscale serve --bg --https=8443 http://127.0.0.1:5300
sudo docker exec tailscale_web_1 tailscale funnel status
sudo docker exec tailscale_web_1 tailscale serve status
```

Only if C1 showed a handler at `/` on 443:

```zsh
sudo docker exec tailscale_web_1 tailscale funnel --https=443 --set-path=/ off
```

Port 8443 is `serve` (tailnet only), at the root so the Desk's `/assets` resolve. 443 should now
list `/farmops` and nothing else you did not intend.
