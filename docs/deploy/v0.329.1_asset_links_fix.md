- MC-BARN now has its four hand copies twice: files 111f706fda, f63a1d26a1, 8220093143 and 181d8f8e11 duplicate
  1877436793, 5e44768e69, 3d91f943e5 and e87c486465.

- The hand copies are Frappe's re-encodes of the originals: pixel-identical, different bytes and hash.

**What changed**
- **A link really is a reference:** `link_file` inserts with Frappe's `copy_from_existing_file`, so the row keeps the
  original's file_url and content_hash and the bytes are never reprocessed.
- **What counts as a hand copy:** an asset file named `<ASSET>_<SIDE>_<date>` whose file_url is not a task evidence
  file's. That covers the 20 hand-attached copies and MC-BARN's four bad rows.
