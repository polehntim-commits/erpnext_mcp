**Deploy: v0.243.0 — no-work notices**

**Migrate needed**: two new doctypes (Work Notice, Work Notice Recipient), six settings fields. Two new MCP tools —
`list_work_notices` (read, on) and `send_work_notice` (write, off). New hourly job. No app change yet.
**umbrel.local only.** Apply after v0.242.0.

**1. Build (Tim)**

Push erpnext_mcp main (`__version__ = "0.243.0"`), build the fafo-erpnext image.

**2. Server, over SSH to umbrel.local**

```zsh
sudo docker exec -u frappe -w /home/frappe/frappe-bench fafo-erpnext_server_1 bench --site frontend migrate
sudo docker restart fafo-erpnext_server_1
sudo docker exec fafo-erpnext_server_1 grep __version__ /home/frappe/frappe-bench/apps/erpnext_mcp/erpnext_mcp/__init__.py
```

Expect `__version__ = "0.243.0"`.

**3. Turn it on**

1. ERPNext MCP Settings → **No-Work Notices**: tick it; cutoff (default 18:00), supervisor lead (default 60 minutes),
   **Escalate To** (one user per line; blank = every Farm Manager). Tick **Send Work Notice** for whoever answers
   over MCP.
2. Only an **Enforced** Work Timing rule drafts notices: add `{"type": "block_start"}` to a preset's Actions (v0.240.0).
3. Workers' Employee **Preferred Language** decides English or Spanish; supervisors come from **Reports To**.

**4. Checks**

1. A Spray task assigned to a worker, under the Enforced spray-wind rule, with wind over 10 mph forecast tomorrow.
   After the 17:00 run: `list_work_notices` `status: "open"` shows one notice, Awaiting Supervisor, with the reason,
   next possible day and both texts; the supervisor's phone got a push.
2. `send_work_notice` `choice: "other_work"`, `alternative: "brush pickup, Block 9, 7 am"`: the worker gets it in their
   language; `not_reached` lists anyone with no enrolled phone — call them.
3. Leave one unanswered: after 18:00 it is **Escalated**, Escalate To got a push, and no worker got anything.
4. If the forecast calms after a notice was sent: the notice reads **Lifted**; `choice: "resume"` tells the crew.

**5. Rollback**

Untick **No-Work Notices**. The notices stay as records.
