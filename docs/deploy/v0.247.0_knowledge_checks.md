**umbrel.local only.** Apply after v0.246.0.

Push erpnext_mcp main (`__version__ = "0.247.0"`), build the fafo-erpnext image.

**2. Server, over SSH to umbrel.local**

```zsh

sudo docker exec fafo-erpnext_server_1 grep __version__ /home/frappe/frappe-bench/apps/erpnext_mcp/erpnext_mcp/__init__.py
```

Expect `__version__ = "0.247.0"`.

**3. Turn it on and load the D-6C quiz**

1. ERPNext MCP Settings: tick **Knowledge Checks**; tick **Submit Quiz Attempt** and **Mark Short Answers** for testing.
2. `draft_config` `kind: "quiz"` with the D-6C questions from Tim's document as `body` (`training_type`, `title`,

   `publish_blockers` must be empty (every question needs Spanish).
3. Desk → Farm Config Version `quiz:d_6c_dozer_operator@1` → **Publish** (a person publishes; decision 5).

3. Desk → that Training Evidence → **Sign Off**: Signed off; an Employee Training Record exists for the course with
   you as Supervisor Reviewed By; a Signing Evidence row (role Trainer) points at the attempt.
4. `publish_config` `kind: "quiz"` over MCP is refused (published in the Desk).

**5. Rollback**
