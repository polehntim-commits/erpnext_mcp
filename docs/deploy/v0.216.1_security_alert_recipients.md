# Deploy: Security Alert Recipients (server v0.216.1; no app change)

Patch on v0.216.0. Code plus one migrate; nothing to switch on.

1. Build the image at the commit with `__version__ = "0.216.1"`; `bench --site <site> migrate`.
   Expect one new field on ERPNext MCP Settings, **Security Alert Recipients**, empty. No patch, no data change.
2. Restart the sidecar (it sends the alert).
3. Optional: fill in Security Alert Recipients (e.g. `polehntim@gmail.com`), comma- or
   semicolon-separated. Left empty, alerts go to every enabled System Manager.
4. Check: `get_server_status` → `erpnext_mcp_version: 0.216.1`.

What it changes: the failed-sign-in alert (10 failures in a minute from one address, at most once an
hour per address) now emails Security Alert Recipients instead of Drift Report Recipients. The
weekly drift report is untouched. If v0.216.0's cutover is already under way, this can be deployed
at any point; it does not touch the Funnel or the phones.
