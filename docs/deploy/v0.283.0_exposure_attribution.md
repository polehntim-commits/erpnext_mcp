**Migrate.** MCP Action Log gains three columns (Agent Client, Acting For, Superseded By). ERPNext MCP Settings gains
one setting, *Hide Tools A Generic Tool Covers*, off by default. Tools stay at 1,141; none are added or removed.

**1. Build (Tim)**

Push erpnext_mcp main (`__version__ = "0.283.0"`), build the fafo-erpnext image with `ERPNEXT_MCP_VERSION=0.283.0`.

**2. Server**

```zsh
sudo docker exec -u frappe -w /home/frappe/frappe-bench fafo-erpnext_server_1 bench --site frontend migrate
sudo docker restart fafo-erpnext_server_1
sudo docker exec fafo-erpnext_server_1 grep __version__ /home/frappe/frappe-bench/apps/erpnext_mcp/erpnext_mcp/__init__.py
```

Expect `0.283.0`.

**3. Checks**

1. MCP Action Log: open any row written after the deploy. It shows *Agent Client* (e.g. `claude-code/…` or
   `python-httpx/…`). A call to an old name such as `list_expense_receipts` shows *Superseded By* = `record`; a call to
   `get_company_topology` shows none.
2. The tool list is unchanged while the new setting is off.
3. ERPNext MCP Settings → Attribution: *MCP System User* is set (if empty, calls run as Administrator;
   `plan_mcp_system_user` lists the roles it needs).

**4. Turning hiding on (Tim, when ready)**

Tick *Hide Tools A Generic Tool Covers* and reconnect the MCP client. It only hides an old tool while its generic
tool is switched on (`allow_record`, `allow_document`, `allow_template`, `allow_config`, `allow_share_link`). Before
ticking it, check that nothing which discovers tools from the list (rather than calling by name) depends on an old
name: MCP Action Log, filter *Superseded By* is set, shows every old-name caller.

**Rollback**

Untick the setting (instant), or the v0.282.0 image; the three new columns are ignored by it.
