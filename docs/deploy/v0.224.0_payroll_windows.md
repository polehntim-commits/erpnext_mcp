# Deploy: v0.224.0 — payroll and bookkeeping windows; the payroll calendar

Code plus one migrate (settings, a seeded tile, a daily job). Everything is off; nothing changes until used.

1. Build at `__version__ = "0.224.0"`; `bench migrate`; restart workers.
2. **A payroll run**: ERPNext MCP Settings → **Open a window** → Payroll → 120 minutes. The AI can then
   calculate, preview and submit payroll, post it to the GL, render pay stubs and build the NACHA and
   prenote files and tax-form PDFs. Everything switches off by itself when time is up (a security alert
   says so). You upload the NACHA file to the bank and pay and file through EFTPS / Oregon Revenue Online
   / the CPA — no tool does that.
3. **Month-end bookkeeping**: the same with Bookkeeping (journal entries, invoices, payments).
4. **Calendar**: tick **Payroll calendar and reminders**. HR, Accounts and System Managers see the
   Payroll calendar tile on Today; reminders go to every HR Manager and System Manager (or the listed
   recipients) 7 and 1 days before each due date. If this farm files Form 943 instead of 941, ignore the
   941 rows (the calendar names both).
