**Deploy: v0.240.0 — Go / Hold on Farm Tasks**

**Migrate needed**: six Farm Task fields, two switches; four Work Timing presets seeded OFF. Two new MCP tools —
`check_go_hold` (read, on) and `override_hold` (write, off). No app change yet (the phone shows the start's note).
**umbrel.local only.** Apply after v0.239.0.

**1. Build (Tim)**

Push erpnext_mcp main (`__version__ = "0.240.0"`), build the fafo-erpnext image.

**2. Server, over SSH to umbrel.local**

```zsh
sudo docker exec -u frappe -w /home/frappe/frappe-bench fafo-erpnext_server_1 bench --site frontend migrate
sudo docker restart fafo-erpnext_server_1
sudo docker exec fafo-erpnext_server_1 grep __version__ /home/frappe/frappe-bench/apps/erpnext_mcp/erpnext_mcp/__init__.py
```

Expect `__version__ = "0.240.0"` and, in the migrate output, `Go / Hold presets seeded OFF: go_hold_pruning_canker,
go_hold_spray_wind, go_hold_burn, go_hold_harvest_heat`.

**3. Turn one on**

1. Weather Settings: **Block Forecasts for Work Timing** ticked (v0.239.0).
2. Desk → Compliance Rule → **Pruning: dry spell for wound healing (bacterial canker)** → Approve (decision 5:
   a person switches it on). It speaks to open tasks whose name contains "prun".
3. To make it Enforced instead of Advisory, add `{"type": "block_start"}` to its Actions.

**4. Checks**

1. Make a Farm Task "Prune Block 7" on a Field with a boundary. `check_go_hold` `task: <it>` → Go or Hold, the
   reason, and the forecast values it read. Nothing is written.
2. Start it (phone or `start_farm_task`): the answer carries `go_hold` — "Advisory Hold — started anyway: …" on a
   wet week. The Farm Task's Go / Hold section shows the verdict and the log.
3. With `block_start` added: the start is refused and names `override_hold`. Tick **Override Hold** in ERPNext MCP
   Settings; `override_hold` with a reason; the start goes through and says whose override.
4. Next morning after 06:00: open tasks under a live rule show a fresh Checked At; a Hold whose weather cleared
   reads Go.
5. Inbox: no new alerts from the four presets.
6. Desk → any Asset Register form, browser console: the asset map's build stamp reads 0.240.0 (v0.239.0 had left it
   at 0.238.0; fixed here).

**5. Rollback**

Untick the rule (or remove `block_start`); every start behaves as before. The fields are additive.
