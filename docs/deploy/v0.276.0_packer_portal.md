**Deploy: v0.276.0 — the packer portal**

**Migrate needed.** It adds the doctype Packer Share (its blocks, credentials and access log), the page script and six
MCP switches (three reads ON, three writes OFF). **No phone update and no Funnel change**: the page and the feed live
under the existing `/farmops/api` path. Contract: `docs/contracts/packer_portal_v0_276.yaml`.

**The portal is OFF for every company** until `packer_portal_enabled` is turned on for it. Constancy stays inactive
until its go-live. No share is created by this release.

**1. Build (Tim)**

Push erpnext_mcp main (`__version__ = "0.276.0"`), build the fafo-erpnext image with `ERPNEXT_MCP_VERSION=0.276.0`.

**2. Server, over SSH to umbrel.local**

```zsh
sudo docker exec -u frappe -w /home/frappe/frappe-bench fafo-erpnext_server_1 bench --site frontend migrate
sudo docker restart fafo-erpnext_server_1
sudo docker exec fafo-erpnext_server_1 grep __version__ /home/frappe/frappe-bench/apps/erpnext_mcp/erpnext_mcp/__init__.py
```

Expect `0.276.0`.

**3. For OVF (Tim, at Constancy's go-live)**

1. Give each committed block its **Block Ticker**, the code OVF sees (e.g. MCC, MCW).
2. Check there is an **MRL Record** for each active ingredient you spray and each market OVF ships to. A missing one
   shows as "no record" and holds the block at "Check".
3. Turn on `create_packer_share`, then run
   `create_packer_share company="Constancy Farms, LLC" packer_name="Orchard View Farms" fields="Bing Block" season=2027 markets="US, Canada, Japan, Korea, Taiwan"`.
4. Turn on `packer_portal_enabled` for Constancy. Then run
   `issue_packer_credential share=PKS-… contact_name="<name at OVF>"` for each OVF contact. Each link is shown once;
   send it to that person yourself. Their system can pull `/farmops/api/packer-feed` with the same credential as a
   Bearer token.
5. `list_packer_access_log share=PKS-…` shows who looked at what, and when. `revoke_packer_access` stops one person
   or the whole share.

**4. Checks**

1. Open the link off the farm Wi-Fi. The page shows only the committed blocks, by ticker, and the downloads work
   (CSV, workbook, PDF).
2. A wrong or revoked link shows "Not found."

**Rollback**

The v0.275.0 image. Shares stay and are ignored. Links and the feed stop when the routes go away.
