**Deploy: v0.270.0 — seasonal work lists: winterize this fall**

**Migrate needed.** No phone update: FarmOps 0.54 already shows the tasks, checklists and photo evidence. Contract:
`docs/contracts/seasonal_v0_270.yaml`.

**1. Build (Tim)**

Push erpnext_mcp main (`__version__ = "0.270.0"`), build the fafo-erpnext image with `ERPNEXT_MCP_VERSION=0.270.0`.

**2. Server, over SSH to umbrel.local**

```zsh
sudo docker exec -u frappe -w /home/frappe/frappe-bench fafo-erpnext_server_1 bench --site frontend migrate
sudo docker restart fafo-erpnext_server_1
sudo docker exec fafo-erpnext_server_1 grep __version__ /home/frappe/frappe-bench/apps/erpnext_mcp/erpnext_mcp/__init__.py
```

Expect `0.270.0`, and the migrate line "seasonal programs seeded as drafts (publish in the Desk): fall_winterize,
spring_startup".

**3. Turn winterization on (Tim, in the Desk; a few minutes)**

1. Desk → **Farm Task Template**. Open each "Winterize — …" checklist, edit the items if needed, tick **Enabled**:
   - Sprayer;
   - Tractor / machine / vehicle;
   - Mower / implement;
   - Irrigation;
   - Wind machine;
   - Shop / pump house;
   - Frost protection readiness;
   - Chemical storage.
2. Make sure the **mini excavator** (track hoe) is registered as a Tractor or Vehicle, or add its asset type to the
   "Tractor / machine / vehicle" checklist's Applies To Asset Types and to the program.
3. Desk → **Farm Config Version** → `seasonal_program:fall_winterize@1`. Check the date (10-25) and the freeze (28 °F,
   10 days ahead), and list the companies (blank = all), then **Publish**.
4. The next morning's run raises one task per asset once it fires. To see what it would do now, run
   `list_seasonal_work` and `get_winterize_status`.

The weather trigger needs the forecast on: ERPNext MCP Settings → Forecast Enabled. Without it, only the fixed date
fires.

**4. Checks**

1. Phone (Foreman / Farm Manager): the Today tile **Seasonal work** lists the open winterize tasks, soonest due first.
2. Complete one with its photo. It leaves the tile, and the asset's history shows it.
3. Three days before the freeze, anything still open appears as a compliance alert naming the asset.

**Rollback**

The v0.269.0 image. Raised tasks stay as ordinary Farm Tasks.
